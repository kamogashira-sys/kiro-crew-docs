# 03_deployment — 導入・運用

Kiro Crew の導入方法と運用に関するセクションです。

## OS 別の対応状況早見表

| OS | 導入経路 | 状態 |
|----|---------|------|
| macOS | デスクトップアプリ（ユニバーサルDMG）・ワンライナー・Docker・ソース | フル対応 |
| Linux | デスクトップアプリ（AppImage・x86_64/aarch64）・ワンライナー・Docker・ソース | フル対応 |
| Windows | ソースインストールのみ | 一部機能が `not yet`（[02_windows.md](02_windows.md)参照）。デスクトップ版は未配布 |
